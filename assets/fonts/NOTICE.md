# 서체 고지

이 페이지에는 네이버에서 제공한 나눔글꼴이 적용되어 있습니다.

---

## 사용 서체

| 항목 | 내용 |
|---|---|
| 서체명 | 나눔손글씨 딸에게 엄마가 (Nanum DdarEGeEomMaGa) |
| 지적재산권 | 네이버 · 네이버문화재단 |
| 배포 파일 | `nanum-handwriting.woff2` |
| 원본 형식 | TrueType (.ttf) |
| 변경 사항 | 글리프 손실 없이 woff2로 형식만 변환. 자형·메트릭·글자 구성은 원본 그대로 |
| 적용 범위 | 해설 본문, 도면 SVG 내 주기 |

## 라이선스 요약

네이버 나눔글꼴의 지적재산권은 네이버와 네이버문화재단에 있습니다.

- 개인·기업을 포함한 모든 사용자에게 **무료로 제공**되며 자유롭게 **수정·재배포**할 수 있습니다
- **글꼴 자체를 유료로 판매하는 것은 금지**됩니다
- 저작권 안내와 라이선스 전문을 포함하면 다른 소프트웨어와 번들하거나 재배포·판매할 수 있습니다
- 라이선스 전문을 포함하기 어려운 경우 **출처 표기를 권장**합니다
- 나눔글꼴을 사용한 인쇄물·광고물의 이미지는 나눔글꼴 프로모션에 활용될 수 있으며, 원치 않으면 네이버에 요청할 수 있습니다

정확한 사용 조건은 라이선스 전문을 따릅니다.

**라이선스 전문** — https://help.naver.com/support/contents/contents.nhn?serviceNo=1074&categoryNo=3497

## 이 리포지터리에서의 준수 사항

- 본 서비스는 글꼴 자체를 판매하지 않습니다. 서체는 화면 표시 용도로만 사용합니다
- 위 출처 표기 문구를 **서비스 정보 화면(SCR-008)에 상시 노출**합니다
- 이 파일을 서체 파일과 같은 위치에 두어 재배포 시 함께 전달되도록 합니다
